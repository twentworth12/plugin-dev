Complete color system

Sand surfaces, semantic content tokens for text at three opacity levels, and Alarmalade accents. All mapped to Tailwind utilities.

Custom typography scale

STK Bureau Serif for display, Sans for body. Precise letter-spacing, line-height, and weight for every style in the scale.

Icon extraction pipeline

Node.js script extracts individual SVGs from the Figma sprite sheet. Supports PNG export with custom colors and sizes.

Tailwind 4 integration

Drop-in head snippet with Play CDN, custom theme tokens, and utility classes. Zero build step required.

Component patterns

Buttons, cards, badges, inputs, tabs, modals, and empty states. All pre-styled with the brand's borders-not-shadows approach.

Get started

  1. 1. Clone the plugin

    git clone https://github.com/twentworth12/plugin-dev.git

  2. 2. Install dependencies

    cd plugin-dev/skills/marketing-brand-design && npm install

  3. 3. Add to Claude Cowork

    Point Claude Cowork at the cloned directory. The plugin will be detected automatically via .claude-plugin/plugin.json.

  4. 4. Start designing

    Ask Claude to build any visual output — web pages, PDFs, presentations, social images — and it will use the incident.io design system automatically.
